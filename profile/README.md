# AutoFAB

Open hardware and a managed service for robot cells that tend 3D printers.

AutoFAB puts a robot arm next to your printers and runs production on those machines. The cell hardware — arm, rail, controller, cameras, parts list, and setup docs — is open source in [Robot-Hardware](https://github.com/AutoFAB-dev/Robot-Hardware). AutoFAB software is a managed service: our systems manage production on your machines; it is not open source. **$99 per machine per month.**

## Start here

- **Build a cell from scratch**, or **set one up if you already have the hardware:** [AutoFAB-dev/Robot-Hardware](https://github.com/AutoFAB-dev/Robot-Hardware)
- **Website:** [autofab.net](https://autofab.net)

## Get help

- Managed service or setup password: [info@autofab.net](mailto:info@autofab.net)
- Hardware or docs in this org: walk the [setup path](https://github.com/AutoFAB-dev/Robot-Hardware/blob/main/docs/setup/README.md), then [troubleshooting](https://github.com/AutoFAB-dev/Robot-Hardware/blob/main/docs/troubleshooting.md). Open a [GitHub issue](https://github.com/AutoFAB-dev/Robot-Hardware/issues) if a step is wrong. Never post passwords, claim codes, tokens, or photos that show them.
- Stop fails or the arm moves when it should not: unplug 12 V and [report it privately](https://github.com/AutoFAB-dev/Robot-Hardware/blob/main/SECURITY.md).
